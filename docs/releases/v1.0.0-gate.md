# v1.0.0 gate

Status: proposed with ADR-0015. Nothing here is met until its evidence is
linked beside it.

v1.0.0 is cut when this is demonstrated:

> The Principal approves a plan digest at the start and merges the promotion
> at the end. Everything between is a Manager seat driving the engine inside
> a ratified policy. When the seat cannot decide, the Principal receives a
> typed escalation they can answer from the message alone. Nobody rescues a
> run by hand.

Running unattended is a non-goal (ADR-0014). Cost, speed and convenience work
does not gate this release.

## Definitions

- **Hand operator work**: any action on a run's refs, journal, records, ops
  home, binary or host units taken by a human, or by a session that is not
  the seat acting through the MCP surface. Answering a Type-1 escalation and
  merging the promotion are not hand work.
- **Qualifying run**: approval to merged outcome with no hand operator work,
  no raw-journal or source read by the seat, on an installed release
  candidate.
- **Real park**: a park the engine raised during a qualifying run, not one
  staged for the purpose.

## Gates

### 1. Engine-enforced seat authority

- [ ] Scoped credentials: observer, manager, principal.
- [ ] A manager credential calling a Type-1 tool is refused with a typed code
      naming the scope.
- [ ] Type-1 confirmation happens on a surface the harness's model cannot
      operate, for the exact digest.
- [ ] Decision records carry credential, harness, model where known, and
      policy version.
