# Sworn v1.0.0-rc.2

This release candidate adds the project cockpit. Run `sworn` in an interactive
terminal to open it, or use `sworn tui` explicitly.

## What's new

- Browse local Baton releases and saved Sworn runs, then open their delivery
  graphs from one screen.
- Start or control work only when the current board offers that action. The
  cockpit uses the same checked commands as the CLI and browser board.
- Discover project state without changing Git or creating a Sworn journal just
  to show the board.
- Keep orchestration in Sworn's existing runtime. The cockpit is a view and
  control surface, not a second scheduler.

Baton remains at `v1.0.0-rc.12`. The full command line and local browser board
remain available.

## Install

Sworn currently ships for Linux x86_64:

```sh
brew install --cask swornagent/tap/sworn
```

See the [installation guide](../install.md) for direct downloads, checksums,
and upgrades.
