## What may be re-derived

Useful behaviors to re-express against RC3 interfaces are:

- ref-catalog election with strict canonical failure;
- one immutable Snapshot source;
- generation guards, stale-result rejection and last-good/error visibility;
- loopback Host enforcement, CSP and security headers;
- responsive desktop/mobile layout, skip link, keyboard/focus order and
  reduced-motion behavior;
- opt-in/no-op telemetry and privacy-canary tests; and
- proof that telemetry failure cannot control delivery.

Do not import the old oracle, TUI, polling server, ledger/eval parser, custom
telemetry transport, Bubble Tea/Lipgloss dependencies, settings/API-key UI,
direct agent actions, raw filesystem log views, provider routing or pricing.

## Required RC3 sequence

1. Hard-stop until W1 supplies the captured-ref projection, W3 supplies the
   transaction-bound snapshot/event-offset, multirun, evidence/log/receipt and
   observer seams, and W4 supplies the closed typed command service.
2. Build one `internal/cockpit` projection shared by terminal canonical JSON
   and a standard-library loopback HTTP service. It accepts opaque IDs and
   typed commands only; it is never a scheduler or Baton writer.
3. Add one embedded Web asset and prove desktop/mobile layout, keyboard,
   focus order and automated accessibility in a real browser.
4. Build deterministic eval from one pinned journal snapshot, with canonical
   versioned JSON, changed/corrupt-snapshot refusal and numerator,
   denominator and unknown counts on every aggregate.
5. Add direct Go OTLP/HTTP last: disabled by default, bounded asynchronous
   queue, finite metric labels, allowlisted traces/events, explicit local
   queue/drop/failure/last-success status, hostile-canary privacy tests and
   outage non-interference.

Stop on missing dependency seams, changed T3 module base, a second authority
oracle, inferred progress, cross-store atomicity claims, direct
Git/path/shell/Baton-write surfaces, unreceipted commands, reconnect gaps,
unknown collapsed to zero, eval controlling delivery, OTel logs, vendor
telemetry SDKs, embedded Collectors, unbounded labels or queues, privacy
leakage, or exporter state changing delivery.

Explicitly excluded are LangChain, LangGraph, Langfuse, DBOS, remote scoring,
pricing catalogs and hosted telemetry control. Local journal events remain
delivery facts; they are not an OTLP queue.
