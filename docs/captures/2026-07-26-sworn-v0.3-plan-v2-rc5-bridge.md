## Product target

Sworn v0.3 is the lean Go engine that carries Baton:

- protected exact-plan approval;
- Planner, Implementer, Captain, and fresh read-only Verifier;
- deterministic engine-owned Merge;
- release and track worktrees with bounded safe parallelism;
- one common driver contract with explicit per-role model selection;
- Codex CLI, Claude Code CLI, OpenAI-compatible, DeepSeek, Gemini, and Bedrock
  profiles;
- idempotent SQLite commands/effects and crash recovery;
- one truthful graph projection in terminal and browser views;
- local evaluation plus opt-in, content-free, non-controlling OTel; and
- executable parity with the useful original Coach loop.

Managed inference, hosted credentials, role-specific drivers, model defaults,
silent fallbacks, duplicate Baton lifecycle, LangChain, LangGraph, DBOS,
Temporal, and speculative site claims remain out.

## Migration behaviour

The installed RC3 record line predates Baton 1.0 and uses `baton.plan/v1`.
RC5's state reader accepts only `baton.plan/v2`, so that legacy line is
immutable migration input outside the current plan lineage, not a valid
revision predecessor. The rejected revision-2 proposal proved this with
`INVALID_PLAN_FENCE`.

This one-time format bridge starts `sworn-v0.3.0-baton-v2` at revision 1:

- all seven track and eight slice identities are retained;
- old RC2, RC3, release, track, plan, receipt, proof, and verdict refs remain
  untouched archaeology;
- reviewed W0-W2 product bytes may be replayed, but prior authority and PASS may
  not;
- W3, W4, W5, W6, and W8 keep their stable outcome identities; and
- no outcome is added or retired.

This is not ordinary replanning. Every later change stays on the v2 line,
appends a revision, and invalidates only changed contracts and actual consumers.
Operational retry, recovery, missing projections, or bookkeeping gaps never
cause a plan revision. A new release identity is allowed only when the goal,
target, or authority changes.

  created only `release-wt/sworn-v0.3.0-baton-v2`, and projected all eight

  recording it therefore does not invalidate the target pin.

  certification for every advertised driver family.

  health/drop visibility are explicit acceptance facts.
- The measured 10,464-line legacy baseline and classifier are explicit. Exact
  plan approval supersedes issue #157's provisional numeric budgets with W8's
  bounded line, package, dependency, and binary limits.
