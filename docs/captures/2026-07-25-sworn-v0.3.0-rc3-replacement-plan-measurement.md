## Reproduce the runtime baseline

Run from the Sworn repository:

```bash
measure_base=b2bb28778a4f73f5841bb936a993860d0b10d0ce
measure_w1=c8ddcd89cbfdaab6c94d601631f87840bf7fd7c2
measure_w2=0136a96c4355e60c815b5cab043b54e860d00062
measure_root="$(mktemp -d /tmp/sworn-w5-baseline.XXXXXX)"
trap 'rm -rf -- "$measure_root"' EXIT

git init -q "$measure_root"
git archive "$measure_base" | tar -x -C "$measure_root"

for measure_candidate in "$measure_w1" "$measure_w2"; do
  git diff --binary --full-index \
    "$measure_base" "$measure_candidate" \
    -- . ':(exclude,top).baton/releases/**' |
    git -C "$measure_root" apply --check -

  git diff --binary --full-index \
    "$measure_base" "$measure_candidate" \
    -- . ':(exclude,top).baton/releases/**' |
    git -C "$measure_root" apply -
done

cd "$measure_root"
measure_files=0
measure_lines=0

while IFS= read -r -d '' measure_file; do
  if grep -Eq '^// Code generated .* DO NOT EDIT\.$' "$measure_file"; then
    continue
  fi
  measure_files=$((measure_files + 1))
  measure_file_lines="$(awk 'END { print NR }' "$measure_file")"
  measure_lines=$((measure_lines + measure_file_lines))
done < <(
  find cmd internal -type f -name '*.go' \
    ! -name '*_test.go' \
    ! -path '*/testdata/*' \
    ! -path '*/fixtures/*' \
    -print0 |
    LC_ALL=C sort -z
)

printf 'files=%d lines=%d\n' "$measure_files" "$measure_lines"
test "$measure_files" -eq 29
test "$measure_lines" -eq 10464
```

## Plan consequence

The unresolved W5 placeholder can be replaced by:

> 10,464 non-generated runtime-production physical lines across 29
> `cmd/**` and `internal/**` Go files.

W5's normal target is at most 2,600 added runtime-production lines under
`internal/driver`; 2,601–2,800 requires proof-backed Captain justification,
and more than 2,800 stops for design reconsideration. Generated, support
tooling, test, and fixture growth must still be reported separately.
